## 2.1 与传统群发工具的根本差异

| 维度 | 传统 TG 群发器 | **TeleHubX** |
|---|---|---|
| 核心能力 | 单一群发 | **全场景营销系统** |
| 账号架构 | 单账号 | **客服号 + 广告号 + 多账号编排** |
| 客服 | 无 | **AI 智能客服 + 知识库 + 人工接管** |
| 反风控 | 几乎没有 | **多层反检测：固定 IP + 真机指纹 + 行为模拟** |
| 客户管理 | 仅发送日志 | **结构化线索沉淀 + 归因分析 + 转化漏斗** |
| 多租户 | 单机使用 | **SaaS 化 · 租户隔离 · 角色权限** |
| 智能化 | 0 | **AI 文案变体 + 智能 FAQ + 自动话术** |

## 2.2 三大核心创新

### 创新 1：客服号 / 广告号角色分离架构

传统工具所有账号"一刀切"群发，**TeleHubX 首创账号角色分工**：

- **🤖 客服号 (cs)** — 关闭主动发送，开启 AI 自动回复，被动接待客户
- **📢 广告号 (ad)** — 关闭 AI、执行 Campaign / 剧本 / Warmup，私聊统一引流到客服 Bot
- **客户路径**: 广告号触达 → 客户私聊 → 自动转给客服 Bot → AI 回复 / 人工接管 → 成交

> **效果**: 广告号即使被封，客服阵地不受影响；客服号无主动发送行为，几乎零封号风险。

### 创新 2：4 阶段关键词智能引流 Pipeline

不是无脑搜群加群，而是 **30 天科学拉新流程**：

```
D1-7   → 搜群池 + 质量评分 + 你人工挑选
D8-14  → 加入挑选的群 + 沉淀观察
D15-25 → 爬取群成员 → 写入候选人池
D26-30 → 按优先级触达候选人 → 转线索
```

**为什么需要这一步**：自动「搜+加+爬」流程在 forex/crypto 这类宽泛关键词上几乎全命中 spam-broadcast 群（gigagroup 不能爬成员、全 anonymous 发言）。先评估再人工挑可避免浪费宝贵的加群配额（账号上限约 500 群）。

### 创新 3：AI 智能客服 + 三档可切换 + 双层 Key

| 模式 | 适用 | 成本 |
|---|---|---|
| **Off** | 纯人工 | 0 |
| **FAQ Only** | 标准化产品 | 几乎为 0 |
| **Smart AI** | 复杂咨询 | 按 Token 计费 |

**双层 Key 体系**:
- **租户自有 Key**: 客户聊天用，按租户订阅承担
- **平台兜底 Key**: 广告变体生成、FAQ 自动撰写等内部任务用，**平台买单**

# 三、六大核心功能模块

## 3.1 智能广告投放 (Campaigns)

**4 层架构 · 计划 → 素材 → 执行 → 归因**

- **AI Variant 生成**: 一段文案 → 自动产出 N 种变体（句式 / 表情 / 标点 / 格式微变 + 图片像素偏移）
- **Gaussian 智能间隔**: 不是固定计时器，模拟真人发送节奏
- **多账号并行**: 300 条任务 / 30 个号 = 10 封/号，自动负载均衡
- **群组黑白名单 + FloodWait 自动指数退避**

## 3.2 7 天科学养号 (Warmup)

完全按 Telegram 风控算法逆向工程，**P0–P4 五阶段渐进**:

| 阶段 | 天数 | 主要动作 | 风控信号 |
|---|---|---|---|
| **P0 沉默期** | D1 | 仅在线保活 | 新设备验证 |
| **P1 浏览** | D2 | 浏览 2 个频道 | 像真人探索 |
| **P2 轻互动** | D3 | Follow 1-2 频道 + 点 reaction | 行为多样化 |
| **P3 社交建立** | D4-5 | 加群 + 群内冒泡短句 | 真实社交特征 |
| **P4 综合** | D6-7 | 更新签名 + 多频道浏览 + reaction | 完整画像 |

> 所有动作时间走 Gaussian 随机分布，不会出现"每天 10 点准时浏览"这种机器特征。

## 3.3 AI 智能客服

**Bot API 单一入口**（低风险、无频率限制） + **MTProto 客服号触达备援**

工作流（已在产品中可视化）：

```
客户私信 Bot → 聚合 3s → FAQ 命中? 
  ├─ 命中 → Guardrail 过滤 → 发送
  └─ 未命中 → AI 检索知识库 → Guardrail → 发送 / 转人工
```

**支持的 AI Provider**:

| 提供商 | 适用 | 中文能力 | 成本 |
|---|---|---|---|
| OpenAI GPT-4o | 高质量、多语种 | ⭐⭐⭐⭐ | 高 |
| **DeepSeek V3** | 中文场景 | ⭐⭐⭐⭐⭐ | 极低（推荐） |
| Google Gemini | 多模态 | ⭐⭐⭐⭐ | 低 |
| Claude Sonnet | 复杂推理 | ⭐⭐⭐⭐ | 中高 |
| 自定义 OpenAI 兼容 | 私有化部署 | 视模型 | 自定义 |

## 3.4 7 类知识库 (Knowledge Base)

**RAG (Retrieval Augmented Generation) + pgvector 语义检索**

## 3.5 人工接管 (Takeover)

当 AI 判断无法回答 / 客户主动呼叫人工 / 触发关键词时：

- **接管即停 AI**：避免 AI 在人工对话中"乱入"
- **广告任务自动跳过该客户**：防止人工沟通中收到群发
- **全程 audit log**：每条消息留痕、每次转手记录
- **WebSocket 实时双向消息**：操作员浏览器即收即回

## 3.6 群源发现与候选人池 (Discovery)

**先评估再行动**的精益拉新模式:

1. **关键词搜群** → 自动评分（gigagroup -30 / channel -50 / 真人发言 +30）
2. **租户人工挑选** 高质量群源
3. **派发加群+爬群任务**，避免浪费加群配额
4. **爬到的成员入候选人池** → 按优先级触达

# 四、技术亮点与安全保障

## 4.1 反检测铁律

> **TG 风控的核心是"行为是否像真人"**。我们用 8 条铁律把账号伪装做到极致：

1. **一号一固定 IP**（住宅 / 4G SIM 代理，永不轮换）
2. **广告号与客服号 IP 段不重叠**
3. **变体文案相似度 < 70%**
4. **ChatScript 多角色对话剧本，一天一群一次**
5. **加群配额 ≤ 2 个/天/账号**
6. **自建群只跑剧本，不日常用广告号**
7. **FloodWait 自动指数退避**
8. **Health Score 0-100 实时监控**
   - 80+ 健康 / 60-80 黄（降频）/ 30-60 橙（暂停部分）/ <30 红（账号隔离）

## 4.2 设备指纹与会话保护

- **真机指纹**: Samsung SM-S928B / Android 14 / Telegram 10.14.2 / 马来西亚住宅 IP
- **TG 后台显示**: "手机 App 登录"，与电脑 / Web 登录痕迹完全不同
- **Session AES-256 加密存储**，密钥与数据库分离

## 4.3 多租户数据隔离

- **租户级行级隔离**: 所有业务表带 `tenantId` 列，service 层强制校验
- **JWT + 角色权限**: SUPER_ADMIN / ADMIN / OPERATOR / VIEWER 四级
- **API 全链路防越权**: 任何 `findOne(id)` 都校验 `entity.tenantId == caller.tenantId`
- **Socket.IO 实时消息也走 JWT 鉴权**，禁止跨租户监听

# 八、常见问题 (FAQ)

**Q1: 会被 Telegram 封号吗？**
A: 我们用 8 条反检测铁律 + 真机指纹 + 住宅代理 + Gaussian 行为模拟，正常使用场景下封号率 < 3%。我们提供 **Health Score 实时监控** + **自动隔离机制**，降低风险。

**Q2: 上手难度大吗？**
A: 平台自带 7 天 onboarding 流程 + 中文操作文档（详见《用户使用指南》）+ 可视化操作界面。新客户平均 **1-2 天**即可上手核心功能。

**Q3: 数据安全怎么保障？**
A: 全链路加密、单租户数据隔离、密码哈希、Session 加密存储、审计日志，符合主流数据保护标准。SaaS 模式数据存于平台 VPS；独立部署模式数据 100% 在客户自己服务器。

**Q4: 支持中文 / 英文 / 其他语言吗？**
A: 客服 AI 支持 **30+ 语种**（基于 OpenAI / DeepSeek / Gemini 模型能力）。系统界面当前为中文，可定制其他语言。

**Q5: 必须用我自己的 Telegram 账号吗？**
A: 是。客户提供自己的 TG 账号（手机号 + SIM 卡），平台帮你绑定、养号、运营。客服 Bot 也由客户在 @BotFather 注册。

**Q6: 与 ChatGPT 直接对接的方案有什么区别？**
A: ChatGPT 单纯 AI 模型，**没有反封号、没有 Telegram 协议层、没有多账号编排、没有客户管理**。TeleHubX 是把 AI 集成到完整的 TG 营销系统里。
